# 🌿 CropSense AI

An AI-powered crop disease detection web app that helps farmers identify plant diseases instantly by uploading a photo of a crop leaf.

## 🧠 How It Works
1. User uploads a photo of a crop leaf
2. Google Gemini Vision AI analyzes the image
3. The app returns: crop name, disease name, severity, cause, and treatment
4. Results are saved to the user's personal history dashboard

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **AI:** Google Gemini 2.0 Flash (Vision)
- **Database & Auth:** Supabase
- **Deployment:** Vercel
